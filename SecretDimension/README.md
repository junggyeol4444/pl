# SecretDimension 플러그인

특정 조건을 충족하면 열리는 3개의 비밀 차원 시스템입니다.

## 명령어
- `/차원` - 발견한 차원 목록 확인

## 차원 입장 조건
| 차원 | 조건 |
|------|------|
| 수정 동굴 | 다이아 블록 4개 이상 + 엔더 아이 우클릭 |
| 어둠의 미궁 | 밤 + 위더 스켈레톤 두개골 3개 + 소울 모래 우클릭 |

## 하늘 섬
Y=200 이상 고도에서 특별한 조건 충족 시 입장.

## 차원 내부
- 제한 시간 내에 탐험 후 보상 획득
- 시간 초과 시 원래 위치로 자동 귀환
- 보스바로 남은 시간 표시
