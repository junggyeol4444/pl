# SupplyBox 플러그인

설정된 시간 간격으로 월드 랜덤 좌표에 보급 상자를 낙하시킵니다.

## 명령어
- `/보급` - 다음 보급 상자 낙하 시간 확인

## 보급 상자 등급
| 등급 | 기본 확률 | 색상 |
|------|----------|------|
| 일반 | 70% | 흰색 |
| 희귀 | 25% | 파란색 |
| 전설 | 5% | 금색 |

## config.yml 설정
- `drop-interval-minutes`: 보급 간격 (분)
- `drop-range`: 드랍 범위 (블록)
- `auto-despawn-minutes`: 미개봉 상자 소멸 시간
- `grade-chances`: 등급별 확률 (합계 100)
- `loot-tables`: 등급별 아이템 목록
